Deflated Sharpe ratio In plain words: a Sharpe ratio that has been marked down for how many things you tried before finding this one. Ten attempts at random will produce one decent-looking Sharpe; the deflated version asks whether yours is better than that. Precisely: the probability that the true Sharpe ratio exceeds the expected maximum Sharpe of N independent trials, adjusted for the length of the test and for skew and kurtosis of the returns (Bailey and Lopez de Prado, 2014). In this tool: N comes from the experiment's trial counter, which is why every run increments it. Good: 0.95 or higher. Used by: leaderboard ranking, validation gate 3. Related: probability of backtest overfitting, trial budget, minimum track record length.
Explain this page: Runs
What you are looking at A list of everything you have run, and a form to start a new run. A run is one strategy with one set of parameters on one data snapshot with one set of fill assumptions. How to read it Compare runs within the same experiment, not across experiments; they share a trial budget and a holdout. "Deflated Sharpe" is the honest score; "Trial" shows how much has been tried. What to do next Open a run to read its plain-language summary and warnings. Select two runs and press Compare. When a configuration looks stable, press Validate rather than running more variants. Common mistakes Picking the single best run from a sweep (choose the plateau). Running variants after seeing holdout results (the tool blocks this). Comparing runs with different realism profiles (flagged).
